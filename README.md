# Library for the VEML6035 ambient light sensor

The [VEML6035](https://www.mouser.de/ProductDetail/Vishay-Semiconductors/VEML6035?qs=u16ybLDytRbGlqopHyj3nQ%3D%3D&srsltid=AfmBOorKfk53Xm7OTFnzyiREUPfQCI7ET6t38CoOKafSEvTKuKP3PCzg) is an ambient light sensor (ALS) from Vishay.

This is a library for this ALS derived from Sparkfun's library for the similar [VEML6030](https://github.com/sparkfun/SparkFun_Ambient_Sensor_VEML6030).
If you need examples on how to use this library please refer to the original library from Sparkfun, as this one works the same.

However I have added funktions to read the RAW light and white light values as well as functions to set the high and low threshold for the interrupt in raw instead of only flux values.
